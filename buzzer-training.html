关键控制代码分析（实训要求三）

① 引脚复用 —— 蜂鸣器接到哪

pinctrl_set_mux(BEEP_PIN, PINCTRL_PINFUNC_PWM);

BEEP_PIN = 9。任务书硬件概述：交通灯板的蜂鸣器 BEEP 与底板 A9 相连，底板左边 A9 对应核心板 GPIO 9。WS63E 的引脚是复用的，必须先用引脚复用函数把 GPIO9 从普通 IO 切换为 PWM 输出功能，PWM 波形才能从该引脚输出到蜂鸣器。

② PWM 参数 —— 频率定音调、占空比定音量

static pwm_config_t g_pwm_cfg = { .freq = 2000, /* 2kHz 决定音调 */ .duty = 500, /* 500/1000 = 50% */ };

PWM（脉冲宽度调制）：占空比是一个周期内高电平时间占整个周期的百分比。蜂鸣器是靠振动膜发声的，方波频率决定振动快慢（音调高低），占空比决定每个周期的高电平能量（响度）。2kHz / 50% 是蜂鸣器最响亮的典型参数。

③ 打开并启动 PWM —— 鸣响的开始

uapi_pwm_open(BEEP_PWM_CHANNEL, &g_pwm_cfg); uapi_pwm_start(BEEP_PWM_CHANNEL);

uapi_pwm_open(channel, cfg) 按配置初始化指定 PWM 设备（依赖 pwm.h）；uapi_pwm_start(channel) 启动输出。start 之后引脚上立刻出现 2kHz 方波，蜂鸣器鸣响 —— 对应任务书「步骤一：初始化 PWM 配置参数 / 步骤二：打开指定 PWM 设备」。

④ 响 3 秒后停止 —— 本次实训的代码修改点

osal_msleep(3000); /* 鸣响 3 秒 */ uapi_pwm_stop(BEEP_PWM_CHANNEL); /* 停止输出方波 */ uapi_pwm_close(BEEP_PWM_CHANNEL); /* 关闭 PWM 设备 */

任务书原工程是持续鸣响；本次实训允许修改代码：延时任务阻塞 3 秒后调用 stop 停止 PWM 输出，再 close 释放设备。stop 后引脚保持低电平，蜂鸣器失电停止鸣响 —— 实现「响 3 秒以后就停止」。

⑤ 音乐演奏 —— 频率随乐谱变化

static const note_t g_song[] = { {NOTE_C4,350},{NOTE_C4,350},{NOTE_G4,350},... }; for (i = 0; g_song[i].ms > 0; i++) { cfg.freq = g_song[i].freq; /* 换音调 */ uapi_pwm_open(CH, &cfg); uapi_pwm_start(CH); osal_msleep(g_song[i].ms); /* 持续该音符 */ uapi_pwm_stop(CH); /* 停顿分音 */ osal_msleep(60); }

音调由频率唯一决定：C4≈262Hz、D4≈294Hz、E4≈330Hz、F4≈349Hz、G4≈392Hz、A4≈440Hz。把《小星星》译成「音符-时值」数组，循环中不断改 PWM 频率并启停，就得到旋律；网页示波器会同步显示每个音符对应的方波。

⑥ 网页如何模拟真实硬件

osc = ctx.createOscillator(); osc.type = "square"; /* 方波 = PWM 音频等效 */ osc.frequency.value = 2000; osc.connect(gain).connect(ctx.destination);

浏览器无法直接访问 Windows 的硬件蜂鸣器，网页使用 Web Audio API 的方波振荡器驱动电脑扬声器 —— 方波正是 PWM 波形的音频等效：频率对应音调、增益对应占空比能量。PWM 示波器则用 Canvas 按相位累加法逐帧绘制真实方波。
